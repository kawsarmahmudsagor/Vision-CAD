PYTHON SERVICE FILES (NEW) - 415 lines total
================================================================================

✨ render_service.py (109 lines)
   Purpose: Render OpenSCAD code to PNG images
   
   Functions:
   - async render_scad_to_png(scad_code: str) -> bytes
     Renders SCAD code to PNG bytes
   
   - async render_scad_to_png_file(scad_code: str) -> str
     Renders SCAD code and saves to disk, returns filepath
   
   Details:
   - Writes SCAD to temp file
   - Calls OpenSCAD CLI with camera parameters
   - Returns PNG bytes or saves to file
   - Handles cleanup of temp files
   - Camera: isometric (800x600, 60°, 45°, distance=80)

✨ comparison_service.py (124 lines)
   Purpose: Use vision model to compare rendered output vs input image
   
   Functions:
   - async compare_renders(input_bytes, rendered_bytes, iteration) -> dict
     Compares input image vs rendered PNG
     Returns: {is_satisfied, confidence, feedback, reasoning, raw_response}
   
   - async get_comparison_feedback(...) -> str
     Gets only the feedback text for code refinement
   
   Details:
   - Encodes both images to base64
   - Sends to vision model (uses existing VISION_MODEL from config)
   - Parses structured response (SATISFIED, CONFIDENCE, FEEDBACK, REASONING)
   - Provides actionable feedback for code refinement
   - Temperature: 0.3 (consistent evaluation)

✨ refinement_service.py (182 lines)
   Purpose: Orchestrate the main iterative refinement loop
   
   Functions:
   - async refine_until_satisfied(...) -> dict
     Main loop: render → compare → refine → repeat
     Returns: {final_scad_code, iterations, satisfied, final_png_bytes, 
               feedback_history, render_history}
   
   - async single_refinement_step(...) -> dict
     Single iteration (for debugging/testing)
   
   Details:
   - Configurable max_iterations (default 10)
   - Configurable confidence_threshold (default 0.75)
   - Handles render errors (requests syntax fix)
   - Tracks all feedback and renders
   - Graceful failure recovery

MODIFIED PYTHON FILES - ~240 lines added
================================================================================

✏️  codegen_service.py (+90 lines)
   Added function:
   - async refine_scad_code(current_code, visual_feedback, description, prompt) -> str
     Refines existing OpenSCAD code based on visual feedback
     Uses: STRICT_CODE_PROMPT + ITERATIVE_REFINEMENT_PROMPT
     Temperature: 0.2 (precise modifications)
   
   When used:
   - Called during refinement loop (step 4)
   - Takes current code + visual feedback
   - Returns modified code

✏️  prompts.py (+60 lines)
   Added:
   1. ITERATIVE_COMPARISON_PROMPT
      - Guides vision model for structured comparison
      - Expects output format: SATISFIED, CONFIDENCE, FEEDBACK, REASONING
      - Enforces specific, actionable feedback
      - No code suggestions, only visual descriptions
   
   2. ITERATIVE_REFINEMENT_PROMPT
      - Guides code model during refinement
      - Emphasizes minimal, targeted changes
      - Preserves code structure and organization
      - Returns only raw OpenSCAD code

✏️  schemas.py (+30 lines)
   Added Pydantic models:
   1. IterativeRefinementRequest
      - scad_code: str
      - input_image_bytes: str (base64)
      - max_iterations: int = 10
      - confidence_threshold: float = 0.75
      - vision_description: str = ""
      - user_prompt: str = ""
   
   2. IterativeRefinementResponse
      - final_scad_code: str
      - scad_file_path: str
      - iterations: int
      - satisfied: bool
      - final_png_bytes: Optional[str]
      - feedback_history: List[dict]
      - render_history: List[dict]

✏️  generate.py (+60 lines)
   Added:
   1. Import: from refinement_service import refine_until_satisfied
   2. Import: import base64
   3. Import: from schemas import IterativeRefinementRequest, IterativeRefinementResponse
   
   New endpoint:
   - POST /api/v1/refine-iterative
     Orchestrates iterative refinement loop
     Request: IterativeRefinementRequest (JSON)
     Response: IterativeRefinementResponse (JSON)
     
   Features:
   - Base64 image decoding
   - Error handling (400, 500)
   - Calls refine_until_satisfied()
   - Saves final SCAD to disk
   - Returns complete feedback history

   Updated docstring to document new pipeline
